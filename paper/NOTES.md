# Papers in this folder

## `CS410_Personalized_Spotify_Milestone.pdf`

Course milestone for CS 410 (UIUC), "Personalized Spotify: Enhancing Emotional Intelligence Through Music," by Rishab Doshi, Kavin Jindel, and Adit Agarwal.

The writeup describes journal-entry sentiment (TextBlob, VADER) matched to Spotify audio features for mood playlists. It is the closest local file to a white paper on music and psychological state. It does not analyze running or Apple Watch data.

## `HarmoniAI_Submission.pdf`

Cozad / startup submission. Pitch for AI edits to a listener's own tracks, with optional wearable input (Apple Watch, Fitbit, Oura). This is product framing, not a results paper. The matching prototype is `src/tune.py`.

## Trends report

The statistical report for the pop-feature study lives in the original notebook (`spotify-trends-main/analysis.ipynb` in Downloads). Findings from that notebook are restated in the README and regenerated by `src/analyze.py`.
