# Archive

Earlier documents from the same line of work. They are kept for history and are not part of the
running-physiology analysis in this repo.

| File | What it is |
| --- | --- |
| `personalized_spotify_mood_report.pdf` | Progress report by Rishab Doshi, Kavin Jindel, and Adit Agarwal on matching journal-entry sentiment (TextBlob, VADER) to Spotify audio features for mood playlists. `src/mood_playlist.py` is the later valence-band ranking helper from that work. It does not analyze running or heart-rate data. |
| `harmoniai_pitch.pdf` | Product pitch for AI edits to a listener's own tracks with optional wearable input. Product framing, not a results paper. `src/tune.py` is the matching audio-edit prototype. |

Neither document is a controlled study of psychological effect, and nothing in this repo tests one.
